Grid Info Service

When a wildfire, evacuation, or highway closure hits the central Sierra, the people who need the facts first are neighbors, ham operators, and responders spread across county lines. The Grid Info Service pulls the authoritative feeds — CAL FIRE, Cal OES, the National Weather Service, USGS, CHP, and Caltrans — into one real-time picture and serves it to anyone, free, with no key and no strings. Every value on this site is a live browser fetch of that public /v1 API. You can replay every request yourself.

no key required CORS-open
One picture, every hazard
Wildfire, evacuation, weather alert, fire weather, earthquake, and road incidents — normalized from a dozen upstream feeds into one queryable event model with full revision history. Ask once; get the whole region.
Honest by contract
Every feed reports OK / STALE / UNAVAILABLE. A source that fails says so — absence is never shown as an all-clear. Life-safety data you can trust because it tells you when it can't.
Built to be built on
Public, keyless, CORS-open, RFC 7946 GeoJSON. Any website, map client, or radio-room dashboard can consume it directly. This site is just one client of the same API — nothing here is privileged.

Endpoints

  

    
      GET
      /v1/sources
      Per-source feed health: poll interval, last success, staleness, last error.
    
    
      GET
      /v1/events
      Cross-layer event query — the one endpoint every occurrence is reachable through.
    
    
      GET
      /v1/places · /v1/places/resolve
      Areas, counties, towns, zones, corridors — plus lat·lng / address resolve.
    
    
      GET
      /v1/places/{place}/map/{layer}.geojson
      RFC 7946 FeatureCollection per hazard layer, with the honest-freshness metadata block.
    
    
      GET
      /v1/history
      Chronological revision feed over a time range — the after-action view.
    
    
      GET
      /v1
      Full reference: severity ramp, place id scheme, the evacuation fail-loud contract.
