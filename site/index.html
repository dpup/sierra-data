Grid Info Service

Public hazard, road, and weather data for the central Sierra.

This site is the live documentation and explorer for the Grid Info Service API at data.sierragridteam.org/v1. Everything on every page is fetched in your browser from the same public, read-only, CORS-open endpoints any third-party client would use — wildfire, evacuation, weather-alert, earthquake, and road-incident events, plus place geometry and per-source feed health. Each section below documents one endpoint and explores its live data; the footer of every page lists the exact requests behind it.

Sections

Sources GET /v1/sources Feed health board: poll intervals, last success/attempt, staleness, last error. The ops dashboard. Events GET /v1/events — cross-layer query Filter by place, layer, status, severity, time; event detail with revision timeline and diffs. Places GET /v1/places, /v1/places/resolve Areas, counties, towns, zones, corridors; geometry on a map; lat/lng and address resolve tester. Map GET /v1/places/{place}/map/{layer}.geojson Per-layer GeoJSON previews with the honest-freshness metadata block, on MapLibre. History GET /v1/history Archive browser: chronological revision feed over a time range — the after-action view. Docs /v1 reference Endpoint reference, severity scale and color ramp, place id scheme, evacuation fail-loud contract.
