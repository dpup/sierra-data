Events — explorer

The cross-layer query surface: GET /v1/events?place=&layer=&status=&severity_min=&since=&page_token=&page_size=. Every discrete occurrence — wildfire, evacuation, weather alert, earthquake, road incident, and the rest — is reachable through this one endpoint; the filters below map 1:1 to its query parameters (layer and status repeat). Default status filter is ACTIVE,SCHEDULED (the API's own default). Results are the snake_case protojson of grid.v1.EventList, server-sorted severity-first then newest-first, paginated by next_page_token. This page's URL carries the full filter state — any view here is a shareable permalink.
