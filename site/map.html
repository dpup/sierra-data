Map — layer previews

Each hazard layer is served as one RFC 7946 FeatureCollection from GET /v1/places/{place}/map/{layer}.geojson — exactly what a third-party map client (MapLibre, Leaflet, QGIS) would point a GeoJSON source at. Features share a common properties envelope (id, layer, severity, headline, source, updated_at) colored here on the canonical severity ramp. The sidebar renders each response's metadata member — the honest-freshness contract: source_status of OK, STALE, or UNAVAILABLE. An UNAVAILABLE layer draws nothing, and nothing on the map is not an all-clear.

Controls

Feed metadata

Per-layer metadata: source status, freshness, attribution, and the exact .geojson URL. This block is why a consumer can trust — or knows not to trust — what the map shows.

Unlocated features

Features with "geometry": null — e.g. a county-wide advisory — are valid and can't be drawn on the map, so they are listed here instead.
